# Workspace Handoff

Use this skill when the Office document has been saved and the companion has access to the surrounding folder.

## Rules

- Treat the document folder as the working directory.
- Read AGENTS.md, SKILL.md, and adjacent source or documentation files when they are relevant to the Office task.
- Keep filesystem actions local to the saved document workspace unless the user explicitly requests otherwise.
- Use Office tools for the document itself and filesystem tools for supporting artifacts, source code, or reference files.
