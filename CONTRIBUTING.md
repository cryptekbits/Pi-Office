# Contributing To Pi-Office

## License

By contributing to Pi-Office, you agree that your contribution may be used and distributed under the [`Pi-Office Personal Non-Commercial License v1.0`](LICENSE) unless a separate written agreement says otherwise.

## Originality

Pi-Office can study other Office assistants for user expectations and capability gaps, but contributions must be original Pi-Office work.

- Do not copy competitor source code, prompts, UI text, assets, private API contracts, or bundled resources.
- Re-spec useful ideas in Pi-Office terms: user problem, public API basis, original UX, implementation files, and validation evidence.
- Update `docs/provenance.md` for any competitor-inspired feature before it is release-bound.
- Keep local captures, downloaded bundles, private traces, and screenshots out of release source.
- Third-party logos or brand marks need a source/license note or a neutral fallback before public packaging.
